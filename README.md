# 桌面代辦 FloatingTodo

Windows 桌面代辦事項懸浮視窗。

## 下載安裝
到 [Releases](https://github.com/Tsukiinuhibi/FloatingTodo/releases/latest) 下載 `FloatingTodo-Setup-x.x.x.exe`，雙擊即自動安裝。
（沒有數位簽章，Windows 跳出「已保護您的電腦」時，點「其他資訊 → 仍要執行」。）

安裝後程式會自動檢查新版本，有更新時視窗上方會出現「立即更新」。

## 功能
- 📌 左上角大頭釘：保持在所有視窗最上層
- 即時日期時間（Windows 系統時間）、月曆、每天幾點要做什麼
- 日曆標示台灣國定假日、補假、補班日與連假，並顯示下一個假期；每天自動從政府辦公日曆表更新
- 必做區：每日／每週（可指定週幾）／每月（可指定日期範圍）／每季／每年
- 右側箭頭滑出「其他週期」：不定期（週期性：每 N 天／週／個月；一次性：單日／跳日／期間）、半年（指定起始年月日）
- 必做事項依各自週期提前顯示在未來日期的行程；有指定日子的事項在日曆上以紫色點標示
- 每個事項右側 ⋯ 可編輯／複製／刪除（刪除前再確認）
- 每個事項都可逐條加備註，每條可複製／編輯／刪除，也可全部複製
- 新增事項時顯示以前輸入過的內容（滾動式選單）
- 到期前 1 小時未完成 → Windows 通知提醒
- ⚠️ 重要注意事項：可自訂分類，像記事本一樣逐條記錄；行程與必做事項點 ☆ 即可加入「標記的行程」
- 🏢 關於公司的小事（頁面預留，之後設計）
- ⚙ 設定
  - **配色**：8 個部位可自訂，RGB 色環＋滴管、螢幕滴管、預覽後再套用
  - **繼承資料**：匯出繼承檔 → 新電腦匯入，確認同一使用者後合併
  - **回信**：關閉程式時把繼承檔寄到指定信箱（Gmail 或自訂 SMTP），並在本機「文件\桌面代辦備份」留一份
  - **更新**：顯示版本、手動檢查更新

## 開發
```
npm install
npm start          # 執行
npm run dist       # 打包 Windows 安裝檔（dist/）
```

## 發布新版本
1. 修改 `package.json` 的 `version`
2. （可選）本機 `npm run dist` 測試打包
3. 推送到 main，GitHub Actions 會自動在 Windows 上打包並發布 Release
