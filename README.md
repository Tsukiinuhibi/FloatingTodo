# 上班便利小工具（FloatingTodo）

Windows 桌面小工具，一個視窗兩種功能，用標題列的「代辦／客服文本」分頁切換：
- **代辦**：桌面代辦事項懸浮視窗（原 FloatingTodo）
- **客服文本**：客服回覆文本（原 CSR，v1.0.0 起整合進來）

> 內部名稱仍是 `FloatingTodo`（安裝檔名、資料夾 `%APPDATA%\FloatingTodo`），舊版桌面代辦會直接自動更新上來，資料不會遺失。

## 下載安裝
到 [Releases](https://github.com/Tsukiinuhibi/FloatingTodo/releases/latest) 下載 `FloatingTodo-Setup-x.x.x.exe`，雙擊即自動安裝。
（沒有數位簽章，Windows 跳出「已保護您的電腦」時，點「其他資訊 → 仍要執行」。）

安裝後程式會自動檢查新版本，有更新時視窗上方會出現「立即更新」。

## 操作方式
- **左鍵點文字＝複製**（對話框、注意事項、條列事項、備註、小按鈕內容）；拖曳選取部分文字時只複製選取的部分
- **右鍵＝其他操作**：編輯、刪除、移動、釘選、設定群組、建立副本、新增備註／細節、重新命名分類或群組等
- 雙擊文字仍可直接編輯（代辦事項、備註、細節、條列事項）

## 功能
- 📌 左上角大頭釘：保持在所有視窗最上層
- 即時日期時間（Windows 系統時間）、月曆、每天幾點要做什麼
- 日曆標示台灣國定假日、補假、補班日與連假，並顯示下一個假期；每天自動從政府辦公日曆表更新
- 必做區：每日／每週（可指定週幾）／每月（可指定日期範圍）／每季／每年
- 右側箭頭滑出「其他週期」：不定期（週期性：每 N 天／週／個月；一次性：單日／跳日／期間）、半年（指定起始年月日）、無限期（沒有期限，完成前每天顯示在今天的行程）
- 必做事項依各自週期提前顯示在未來日期的行程；有指定日子的事項在日曆上以紫色點標示
- 事項按右鍵可編輯／複製文字／建立副本／刪除（刪除前再確認）
- 必做事項可加第二階層「細節」，完成時會封存當下細節成紀錄（📜 完成紀錄），之後增減細節不影響已完成的紀錄；行程頁也會顯示細節（已完成下移、超過 3 項可捲動）
- 每個事項都可逐條加備註，每條可複製／編輯／刪除，也可全部複製
- 新增事項時顯示以前輸入過的內容（滾動式選單）
- 到期前 1 小時未完成 → Windows 通知提醒
- 🕔 下班前提醒：每個上班日、下班前（預設 1 小時，可調整）彙總通知今天還沒完成的必做事項；上班日 = 週一到週五，扣掉國定假日與補假，加上補班日
- 日曆日期按右鍵可自訂補班／補休（兩個日期可一起設定），自訂的日子有紫色底線
- ⚠️ 重要注意事項：可自訂分類，每個分類有「條列事項」（逐條記錄）和「記事本」（自由書寫、自動儲存），都可新增／編輯／刪除
- ⚠️ 重要注意事項的條列事項可以釘選、標紅字（`[[文字]]`），和客服文本右側的注意事項是同一份資料
- 🏢 關於公司的小事（頁面預留，之後設計）
- 💬 客服文本：分類頁面、分類群組、對話框（可加名稱）、職安注意事項的小按鈕、搜尋、移動、只複製選取的文字
  - 固定分類：工作訊息回覆、職安注意事項、公司報告登入（後兩個的對話框可加小按鈕）
  - 右側注意事項可選要顯示 ⚠️ 重要注意事項的哪個分類（預設「客服注意事項」）
  - 「文字與版面」調整字體大小；拖曳分隔條調整區塊大小
  - 匯出／匯入 .txt 備份，格式與舊版客服回覆文本相容（舊版資料請用這個方式搬過來）
  - 資料存在 `%APPDATA%\FloatingTodo\csr-data.json`
- ⚙ 設定
  - **配色**：8 個部位可自訂，RGB 色環＋滴管、螢幕滴管、預覽後再套用
  - **配色**也套用到客服文本頁
  - **繼承資料**：匯出繼承檔 → 新電腦匯入，確認同一使用者後合併（包含客服文本）
  - **回信**：關閉程式時把繼承檔寄到指定信箱（Gmail 或自訂 SMTP），並在本機「文件\桌面代辦備份」留一份
  - **上班**：下班時間、下班前提醒（開關、提前多久）、自訂補班／補休清單
  - **更新**：顯示版本、手動檢查更新

## 開發
```
npm install
npm start          # 執行
npm run dist       # 打包 Windows 安裝檔（dist/）
```

## 發布新版本
1. 修改 `package.json` 的 `version`
2. （可選）本機 `npm run dist` 測試打包
3. 推送到 main，GitHub Actions 會自動在 Windows 上打包並發布 Release
